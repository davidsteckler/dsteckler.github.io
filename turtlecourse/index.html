02where this goes

From instructions to reusable ideas.

A short Turtle program can already contain most of the programming ideas we care about: sequence, repetition, variables, functions, parameters, and debugging.

main.pyfunctions + parameters
def square(size):
    for i in range(4):
        forward(size)
        right(90)

square(50)
square(100)
// ready when you are

The turtle only does what the code says.

That is what makes it useful. When the output surprises you, there is something in the instructions worth finding.
