Meet the Turtle.

Before you make anything complicated, you need to know where the turtle is, which way it is facing, and how to follow the instructions Python is executing.

By the end You can explain the Turtle world and follow a program one line at a time.

You do not need to memorize every command yet.

01start here

The turtle lives on a coordinate grid.

The middle of the world is (0, 0). The first number tells you left or right. The second tells you down or up.

xLeft ↔ Right

Positive x moves right. Negative x moves left.

yDown ↕ Up

Positive y moves up. Negative y moves down.

start(0, 0), facing right

Every fresh Turtle run starts from the center unless your code moves it.

02explore

Change x and y independently. Watch which direction changes each time.

(0, 0) +x −x +y −y
current position (0, 0)
Notice: changing x never moves the turtle up or down. Changing y never moves it left or right.
