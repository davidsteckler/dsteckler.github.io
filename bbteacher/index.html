Black Box

Quick access to the full transmission and every stage of the scavenger hunt.

Physical black box → SD card

Intended opening: students physically open the classroom black box, find the SD card, and discover one sparse file such as signal.txt. The file contains only the binary below. Decoding it leads to https://dsteckler.com/blackbox, where the larger transmission begins.

Keep the SD card minimal: ideally one file, no README, and no explanation of binary. The physical box is the true beginning of the semester-long scavenger hunt.
