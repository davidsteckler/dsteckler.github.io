Python turtle, from the start
Import the library at the top of your program. Then put turtle. before each turtle command.
import turtle

turtle.forward(100)
turtle.left(90)

turtle.done()
Give your turtle a name
Create a turtle object, then use its name to control it. You can create more than one turtle.
import turtle

pen = turtle.Turtle()
pen.color("purple")
pen.forward(100)

turtle.done()
Commands to try
turtle.forward(100)Move forward 100 pixels
turtle.left(90)Turn left 90 degrees
turtle.goto(-100, 50)Move to an x, y coordinate
turtle.penup() / turtle.pendown()Lift or lower the pen
turtle.circle(50)Draw a circle with radius 50
turtle.color("teal")Set the pen and fill color
turtle.begin_fill() / turtle.end_fill()Fill a shape you draw between these calls
turtle.speed(0)Draw at the fastest speed
screen = turtle.Screen()Access the drawing screen
The turtle starts at (0, 0) in the center, facing right. Positive y goes up. Import the library before using turtle names and commands.
