A GOOD PLACE TO START

Your studio, at a glance.

Build a model

Add a shape, then set its dimensions in the properties panel. Select Sketch to draw a rectangle, circle, or polygon on the ground plane and extrude it to a height.

Shift + click selects multiple bodies. Union joins them, Subtract cuts the other selected bodies out of the first one, and Intersect keeps their shared volume.

Move around

Drag empty space to orbit. Right drag to pan. Scroll or pinch to zoom. Use the view buttons for Top, Front, Right, or 3D.

Keep what you make

Changes autosave in this browser on this device. Save project downloads an editable file you can open here later or move to another computer. Browser data can be cleared, so download important work.

Export STL downloads visible bodies as a triangle mesh using millimeters. Check the model and its scale in your slicer before printing. This is a mesh modeling studio; it does not include Shapr3D’s full CAD kernel or sketch constraints.
