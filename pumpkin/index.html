KEEP THIS HANDY

The pumpkin command guide

The editor uses the same Tracy commands as the Turtle page. Type them directly; you do not need import turtle here.

CommandWhat to watch
penup()Move Tracy without leaving a trail.
pendown()Draw while Tracy moves. She starts with her pen down.
setposition(x, y)Move to a point. x goes left/right; y goes down/up.
setheading(0)Face right. 90 = up; 180 = left; 270 = down.
forward(50)Move 50 pixels in the current direction.
left(120)Turn left 120°. Three of these turns make a triangle.
circle(140)Draw a circle with radius 140 to Tracy’s left.
circle(50, 180)Draw half a circle. The second value is the angle.
color("darkorange")Choose the outline and fill color. Hex colors work too.
begin_fill()
end_fill()		Put these around the commands that draw a closed shape.
for i in range(6):Repeat the indented lines six times.
def triangle():Define a function. Call triangle() to run it.
speed(0)Instant drawing. Use 1–10 for animation.
hideturtle()Hide Tracy’s marker while keeping the drawing.

The world is 400 × 400.
The center is (0, 0). The left eye starts left of center and above it, so its x is negative and its y is positive.

Seeing a line between your shapes? Put penup() before moving to the next shape, then pendown() before drawing.
A function or loop will not run? Check the colon and indent its body four spaces. Keep the function’s call outside the definition.
