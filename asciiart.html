ASCII Art & Games

What if a picture was just text? See how ordinary characters became game worlds, then use the same trick to build your own.

01See itRogue, made of text 02Play itExplore a dungeon 03Make itDraw with characters
01 / SEE IT

Before game graphics, there were characters.

In Rogue, a room is drawn with lines and dots. @ is you. $ is treasure. Every symbol is still text.

@One character is the player.The game draws a symbol, not a picture of a person.
#Repeated symbols make spaces.Walls and corridors form a recognizable map.
$Context gives the text meaning.Here, the dollar sign is treasure.

03 / MAKE IT

Make a picture out of text.

Three small experiments, one workspace. Learn why the characters line up, see how they make shades, then draw your own sprite.

// trick 1

Every character needs the same width.

ASCII art depends on a monospace font: every character takes up the same amount of horizontal space.

       /\
      /  \
     /____\
     | [] |
     | __ |
     ||  ||
     ||__||
The columns line up because every character has equal width.
// trick 2

Characters can behave like shades.

Some characters cover very little of the screen. Others are visually dense. Artists can use that difference like light and dark pixels.

 .:-=+*#%@
