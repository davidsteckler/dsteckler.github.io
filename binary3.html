One Byte, Many Meanings

A byte is only eight bits. Those bits do not say what they mean. The program reading them decides how to interpret the value.

1

Choose one byte.

Change any bit, drag the slider, or use a preset. Everything on the next step uses this exact same byte.

01000001
decimal 65 hex 41 8 bits = 1 byte
0drag the byte value255
The byte stays the same.Only the interpretation changes.
2

Read the same byte five different ways.

Every card below receives the exact same eight bits. The result changes because each card follows a different rule.

Interpretation 1

As a number

same byte  01000001
65
Read as an unsigned binary number, this byte equals 65.
Interpretation 2

As text

same byte  01000001
A
ASCII says decimal 65 represents the character A.
Interpretation 3

As a grayscale pixel

same byte  01000001
As 8-bit grayscale, 65 / 255 controls brightness.
Interpretation 4

As one RGB color channel

same byte  01000001
This byte can be the red value in RGB(65, 0, 0).
Interpretation 5

As one audio sample

same byte  01000001
Here, the byte becomes the height of one sample in a waveform.
Same bits. Different meaning. The meaning comes from the format, program, or rule used to read the byte.
