Six small programs are hiding six words. Predict each program's output before you check it. Every solved program will also reveal why Python produced that answer.
program 01 · strings
waiting
message = "I can do hard things"
print(message[0])
prints:
Why: message[0] asks for the character at index 0. Python starts counting at 0, so that is the first character: I.
program 02 · changing a string
waiting
word = "cannot"
word = word.replace("not", "")
print(word.upper())
prints:
Why: replace() removes not, leaving can. Then upper() changes it to CAN.
program 03 · follow the order
waiting
for try_number in range(3):
    print("try again")

print("sit")
last word:
Why: the loop prints try again three times. When the loop ends, Python continues to the next line and prints sit.
program 04 · lists
waiting
words = ["run", "hide", "with", "quit"]
print(words[2])
prints:
Why: list indexes also begin at 0. Index 0 is run, 1 is hide, and 2 is with.
program 05 · variables change
waiting
problem = "easy"
problem = "hard"
print(problem)
prints:
Why: the second assignment replaces the first value. When Python reaches print(problem), the newest value is hard.
program 06 · read exactly
waiting
things = ["loops", "bugs", "errors", "questions"]
print("things")
prints:
Why: quotes change what Python sees. "things" is literal text. Without quotes, things would mean the variable holding the list.
