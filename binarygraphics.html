Graphics & Animation

Computers can show pictures in different ways. Raster images store pixels, vector graphics store drawing instructions, and animation changes pictures over time.

Raster = a grid of pixels.

A raster image remembers the color of each pixel. Zoom in far enough and you eventually see the individual squares.

Photos and screenshots are usually raster images. More pixels usually means more detail — and more data to store.

Vector = drawing instructions.

Instead of storing every pixel, vector graphics describe shapes: lines, curves, circles, fills, and positions.

Logos and icons are often vectors because the same instructions can be redrawn at many sizes without becoming blocky.

Animation = frames changing over time.

Each frame is one image. Show different frames quickly enough and your brain sees motion instead of separate pictures.

The computer still stores data for each frame or instructions for how things move. Animation adds time to visual representation.

Three different ways to represent visuals.

The screen may look similar, but the data underneath can be very different.
